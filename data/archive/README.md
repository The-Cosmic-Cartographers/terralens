# data/archive

Series that were in the app earlier on 14 Nov 2026 and were replaced by the MERRA-2 long record
(1980–2025) so every Lineup row covers about 40 years. They are kept for cross-checks only and are
not read by the data index, the analysis or the export. Each folder keeps its own provenance.

| Folder | What it was | Why replaced |
| -- | -- | -- |
| `gldas_noah025_m21_soilmoi0_10` | GLDAS-2.1 soil moisture 0–10 cm, 2000–2025 | record starts in 2000 |
| `gldas_noah025_m21_evap` | GLDAS-2.1 evapotranspiration, 2000–2025 | record starts in 2000 |
| `gpm_3imergm_v07b` | GPM IMERG Final V07B precipitation, 2001–2024 | record starts in 2000 |
| `merra2_m2tmnxaer_v5_12_4` | MERRA-2 aerosol, 2003–2025 | the same product now runs 1980–2025 |
